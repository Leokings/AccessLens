Use terms

AccessLens provides evidence-backed interface feedback, not a legal accessibility certification or a guarantee that a website is safe or compliant.

Appropriate use

Submit only public HTTPS pages that you are permitted to review. Do not submit private systems, sensitive information, or content you do not have a right to share. The URL and optional focus text become public when an audit finalizes.

How reports work

GenLayer validators independently render the target page and must agree on the same first 48,000 whitespace-normalized HTML characters before a report can finalize. This is one-page, HTML-only advice; it does not test every route, interaction, keyboard or screen-reader behavior, or future page state. Public pages may change, block automation, or render differently, so an audit can fail without a stored report. Treat findings as suggestions to verify, not as definitive facts about every visitor's experience.

The page digest commits to the inspected HTML prefix but does not archive the full page. A comparison link verifies an earlier report on this contract for the same URL; it does not prove page ownership, remediation, or history across contract deployments. See the evidence and lineage explanation.
